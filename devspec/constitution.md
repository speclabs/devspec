# Constitution

This file holds enduring principles that apply across work items and agents.

## Engineering Principles

- Prefer simple solutions over speculative abstractions.
- Keep requirements, implementation, and validation aligned.
- Favor readable, maintainable code over cleverness.

## Delivery Guardrails

- Changes must stay within approved scope.
- Significant scope changes must return to an earlier devspec stage.
- Validation is required before work is considered complete.

## Testing Expectations

- New behavior should have corresponding validation.
- Regressions should be captured in tests when practical.

## Security And Compliance Defaults

- Do not weaken security controls without explicit approval.
- Handle sensitive data according to project and organizational rules.

## Amendment Notes

- Update this file only for durable principles that rarely change.
- Put operational delivery gates and evolving compliance rules in `devspec/foundation/rules.md`.
