# Architecture Decisions

Store long-lived architecture decisions here as ADRs.

`_template.md` is framework-owned and should be used as the section contract for new ADRs. Actual ADR files are project-owned.

Recommended naming:

- `ADR-0001-short-title.md`
- `ADR-0002-short-title.md`

Suggested sections:

- Status
- Context
- Decision
- Consequences
